# CGPA Booster - Final Project

Built using only:
- HTML
- CSS
- Vanilla JavaScript

Features:
- Login and signup using localStorage
- Personalized student dashboard
- CGPA calculator
- Study schedule
- Daily subject-based quiz
- Topic memory/mastery tracking
- Quiz history and accuracy
- Study streak
- Subjects
- Goals
- Resources
- Search
- Dark mode
- Responsive UI

Run:
Open index.html in Chrome/Edge.

Important:
This is a frontend/demo authentication system. Passwords are stored in browser localStorage, so it is not suitable for production security. A real production login needs a backend/database and secure authentication.
