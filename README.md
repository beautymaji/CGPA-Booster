# 🎓 CGPA Booster

### Your Personal Academic Productivity & Study Management Platform

**CGPA Booster** is a student-focused web application designed to help students organize their studies, manage daily schedules, track learning progress, and work toward their academic goals. It provides a personalized dashboard with study planning, quizzes, topic mastery tracking, and CGPA management in one place.

Built using **HTML5, CSS3, and Vanilla JavaScript**, the application focuses on a clean user interface, interactive features, and a responsive experience without requiring a frontend framework.

## 🚀 Live Demo

🌐 **Live Application:** [CGPA Booster](https://cgpa-booster-green.vercel.app/)

📂 **GitHub Repository:** [CGPA-Booster](https://github.com/beautymaji/CGPA-Booster)

## ✨ Features

- **🔐 Login & Signup:** Frontend-based authentication using browser Local Storage.
- **📊 Personalized Dashboard:** View academic information and track study activities in one place.
- **🎯 CGPA Calculator:** Manage CGPA-related academic goals and monitor performance.
- **📅 Study Scheduler:** Organize study sessions, subjects, dates, timings, and topics.
- **📝 Daily Subject-Based Quizzes:** Practice subject-related questions and check answers.
- **🧠 Topic Mastery Tracking:** Track topics using learning statuses such as Not Started, Learning, and Memorized.
- **📈 Quiz History & Accuracy:** Review quiz performance and identify areas that need improvement.
- **🔥 Study Streak:** Monitor study consistency and build productive habits.
- **📚 Subject & Resource Management:** Organize academic subjects and study resources.
- **🔎 Search Functionality:** Find relevant information within the application.
- **🌙 Dark Mode:** Switch to a dark interface for a comfortable viewing experience.
- **📱 Responsive Design:** Use the application across desktop, tablet, and mobile screen sizes.

## ⚙️ Getting Started

Follow these steps to run the application on your local machine.

### Prerequisites

- A modern web browser, such as Google Chrome or Microsoft Edge.
- Git installed on your system (optional, for cloning the repository).
- A code editor such as Visual Studio Code (optional).

### 1. Clone the Repository

```bash
git clone https://github.com/beautymaji/CGPA-Booster.git
```

### 2. Navigate to the Project Directory

```bash
cd CGPA-Booster
```

### 3. Run the Application

Open the `index.html` file in your browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension for local development.

**No Node.js installation or package dependencies are required** to run the basic frontend application.

## 💡 How It Works

1. Open CGPA Booster in your browser.
2. Register or log in using the available frontend authentication interface.
3. Explore the dashboard and organize your academic activities.
4. Create study schedules and track topics you are learning.
5. Practice daily quizzes and review your performance.
6. Use the available academic tracking features to stay focused on your goals.

- Used **Vanilla JavaScript** to implement interactive functionality without relying on frontend frameworks.
- Applied DOM manipulation and event handling to respond to user actions.
- Used **Local Storage** to persist supported data in the browser across sessions.

## 🔒 Security & Limitations

CGPA Booster is currently a frontend demonstration project.

- Authentication is implemented on the client side using browser Local Storage.
- Stored credentials and application data are not protected by a secure backend.
- Local Storage data is specific to the browser and origin; it does not automatically synchronize across devices.
- The application does not currently provide server-side authentication or centralized database storage.

**Important:** Do not use real or sensitive passwords in this demonstration application. A production-ready version should implement secure server-side authentication, password hashing, and a database.
